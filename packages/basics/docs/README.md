# @slidesend/basics

The `section` slide template, generic blocks, the activities `poll`, `text`, `wait` and `link`,
and the neutral default design. Install the nodes with `plugins: [basics()]`; the design is
`defaultDesign`, set as `design` in `presentation.config.ts`.

- Every field of every node, with types and defaults: [nodes](nodes.md).
- How to use them in a deck: [writing-slides](../../core/docs/writing-slides.md#the-nodes-of-slidesendbasics).
- The default design and how to change its colors: [design](../../core/docs/design.md).
- Everything else: [the documentation index](../../core/docs/README.md).
