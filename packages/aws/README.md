# @slidesend/aws

Hosting for slidesend talks on AWS: the backend on AWS Blocks, deploy, bootstrap with OIDC, and the GitHub Actions workflow.

Part of slidesend, a presentation tool for talks in which the audience takes part on their phones.
Start a talk with `npm create @slidesend@latest my-talk`.

The documentation ships with this package: [`docs/deploy-aws.md`](docs/deploy-aws.md), and in the repository at
https://github.com/nxsflow/slidesend.
