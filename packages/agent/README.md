# @slidesend/agent

An AI agent chat for the audience of a slidesend talk, on Amazon Bedrock.

Part of slidesend, a presentation tool for talks in which the audience takes part on their phones.
Start a talk with `npm create @slidesend@latest my-talk`.

The documentation ships with this package: [`docs/agents.md`](docs/agents.md) and the node reference [`docs/nodes.md`](docs/nodes.md), and in the repository at
https://github.com/nxsflow/slidesend.
